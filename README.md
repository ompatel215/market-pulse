# Market Sentiment Tracker
CMPSC 446 Final Project

## Project Goal
Quantify real time market sentiment from Reddit and news to predict volatility 
using statistical anomaly detection

## Setup
1. Clone the repo.
2. Create a `.env` file with your Reddit API credentials.
3. Install dependencies: `pip install -r requirements.txt`
4. Run the dashboard: `streamlit run app.py`
